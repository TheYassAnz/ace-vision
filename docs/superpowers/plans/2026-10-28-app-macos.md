# ACE Vision.app — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remplacer l'appli web Jinja + Safari par une application Mac SwiftUI (`ACE Vision.app`) qui pilote le moteur Python d'analyse via une API JSON locale, publiable en open source.

**Architecture:** Le package Python `ace` garde le pipeline et `store` ; `ace/web/app.py` devient une API JSON protégée par un jeton, lancée par l'app sur un port libre (`python -m ace` imprime `ACE_READY <port>` et s'arrête quand son stdin se ferme). L'app SwiftUI (`app/`, projet XcodeGen) lance ce processus, l'interroge en `async/await`, lit les vidéos directement sur disque avec AVKit et installe au premier lancement l'environnement Python et le modèle YOLO dans `~/Library/Application Support/ACE Vision/`.

**Tech Stack:** Python 3.12 (uv), FastAPI + Uvicorn, Pydantic v2, pytest + httpx ; Swift 6, SwiftUI, Observation, AVKit, PhotosUI (`PhotosPicker`), Swift Charts, UserNotifications, Swift Testing ; XcodeGen (`brew install xcodegen`), Xcode 16+.

**Spec:** `docs/superpowers/specs/2026-10-28-app-macos-design.md` · Spec d'origine : `docs/superpowers/specs/2026-10-23-ace-vision-design.md` · Vocabulaire : `GLOSSARY.md`

## Global Constraints

- macOS **15** minimum (`MACOSX_DEPLOYMENT_TARGET = 15.0`), Apple Silicon (`arm64`) seulement.
- Python **3.12** via `uv` ; le pipeline (`ace/pipeline.py`, `pose`, `strokes`, `technique`, `findings`, `notes`, `video`) ne change pas, sauf le chemin du modèle (Task 2).
- Code et identifiants en **anglais** ; **tout texte visible en français**, vocabulaire de `GLOSSARY.md` (coup, frappe, échange, défaut, constat, match, vue).
- Libellés : coups « Coup droit », « Revers », « Service », « Autre » ; vues « Vue filet », « Vue arrière » ; défauts `late_prep` « Préparation tardive », `small_turn` « Épaules peu tournées », `straight_legs` « Jambes tendues », `narrow_stance` « Appuis serrés ».
- API liée à **127.0.0.1** seulement ; chaque requête porte `Authorization: Bearer <ACE_TOKEN>` (jeton aléatoire de 32 octets généré par l'app à chaque lancement).
- Une seule analyse à la fois (`JobRunner` inchangé) ; un match en cours d'analyse ne se supprime pas et ne se ré-importe pas.
- Accès réseau **uniquement pendant l'installation** (`uv sync`, modèle) ; jamais pendant une analyse.
- Dossier de l'app : `~/Library/Application Support/ACE Vision/` contenant `data/` (= `ACE_DATA_DIR`), `engine/`, `venv/`, `python/`, `cache/`, `models/yolo11m-pose.pt`.
- Modèle : `https://github.com/ultralytics/assets/releases/download/v8.3.0/yolo11m-pose.pt`, vérifié par SHA-256 (valeur prise sur `models/yolo11m-pose.pt` du dépôt, Task 7).
- `ffprobe` requis via Homebrew, cherché dans `/opt/homebrew/bin` puis `/usr/local/bin`.
- Licence **AGPL-3.0** (imposée par Ultralytics).
- **Formats** : nombres, pourcentages, durées et dates passent par `FormatStyle` avec `Locale(identifier: "fr_FR")` (`.percent`, `.number.precision(.fractionLength(1))`, `Duration.formatted(.time(pattern: .minuteSecond))`, `Date.FormatStyle`), jamais de virgule ni de format codé à la main ; chiffres comparés (cartes, barre latérale, pourcentages) en `.monospacedDigit()`.
- **Accessibilité** : chaque bouton à icône seule a un `.accessibilityLabel` ; aucune information n'est portée par la couleur seule ; tout ce qui se fait à la souris ou par glisser-déposer a un équivalent clavier ; les résultats asynchrones (enregistrement des notes, fin d'import) sont annoncés à VoiceOver (`AccessibilityNotification.Announcement`).
- **Textes** : casse de phrase française (pas de Title Case) ; un état en cours finit par « … » ; un message d'erreur dit ce qui s'est passé **et** quoi faire ; un bouton nomme son action (« Enregistrer les notes », pas « OK »).
- **Contenus longs** : titres de match sur une ligne (`.lineLimit(1)`, `.truncationMode(.middle)`, titre complet en `.help`) ; listes longues paresseuses (`List`, `Table`, `Canvas`), un match d'une heure compte plusieurs centaines de coups.
- Commandes : `uv run pytest` ; `xcodegen generate --spec app/project.yml && xcodebuild test -project app/ACEVision.xcodeproj -scheme ACEVision -destination 'platform=macOS'`. `app/ACEVision.xcodeproj` est généré et ignoré par git.

## Review Focus

1. **L'app plante ou est tuée de force (⌘⌥⎋) pendant une analyse** : le processus Python ne doit pas survivre (stdin fermé → sortie), et au relancement le match passe en « Échec » avec « Relancer l’analyse ». → test dans Task 1 (`test_exits_when_stdin_closes`).
2. **Une page web ou un autre programme local appelle l'API** : refusé sans le jeton. → test dans Task 1 (`test_request_without_token_is_401`).
3. **Métriques NaN (chevilles cachées) dans `match.json`** : la réponse de l'API reste du JSON valide et se décode en Swift. → tests dans Task 1 (`test_match_json_is_strict`) et Task 3 (décodage de la fixture).
4. **Installation coupée (Wi-Fi perdu pendant `uv sync` ou le modèle)** : au lancement suivant elle reprend, et un modèle partiel ou corrompu n'est jamais utilisé. → test dans Task 7 (`downloadRejectsBadChecksum`).
5. **Vidéo Photos très lourde ou encore dans iCloud** : le fichier temporaire est supprimé même si l'import échoue, et l'erreur est affichée en français. → test dans Task 5 (`importDeletesTempFileOnFailure`).
